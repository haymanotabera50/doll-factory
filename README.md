## ✨ Features

- **🎮 Procedural 3D WebGL Exhibitions:** Real-time 3D interactive figurines built with Three.js (no heavy 3D asset downloads).
- **🔄 360° Turntable OrbitControls:** Click-and-drag rotation, zoom dampening, and auto-turntable spin.
- **📍 Projected 3D-to-2D Hotspots:** Screen-space pins on crowns, sashes, and regalia opening historical dossiers.
- **💡 Studio Lighting Controls:** Switch between *Studio*, *Warm Sunset Amber*, and *Museum Dramatic* lighting.
- **📐 Topology Inspection:** Toggle between *Standard Finished PBR*, *Clay Violet*, and *Wireframe* modes.
- **🎵 Native Web Audio Synthesizer:** Real-time harmonic chimes generated mathematically via Web Audio API.
- **🏛️ Universal Heroines 3D Pavilion:** Seamlessly switch between all 7 Ethiopian heroines:
  1. *Empress Taytu Betul*
  2. *Empress Zewditu*
  3. *Queen of Sheba (Makeda)*
  4. *Woizero Shewareged Gadle*
  5. *Empress Mentewab*
  6. *Commander Derartu Tulu*
  7. *Werede Mamo*
- **🇪🇹 Bilingual Education:** Complete Amharic & English biographies, spoken voice history narrations, and bedtime storybooks.
- **🛍️ Standardized 7-Inch Format:** Sole 7-inch collector plinth edition (2,250 ETB / $35 USD) with custom brass engraving and certificates of authenticity.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/haymanotabera50/doll-factory.git
cd doll-factory

# Install dependencies
npm install

# Run the local development server
npm run dev

# Build for production
npm run build
```
